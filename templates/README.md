# Templates

Copie o template adequado para o diretório de destino e substitua todos os placeholders.

| Template | Uso |
|---|---|
| `adr-template.md` | Decisão arquitetural significativa |
| `experiment-template.md` | Hipótese, PoC ou benchmark |
| `assessment-template.md` | Avaliação comparativa, maturidade ou risco |
| `study-note-template.md` | Estudo ainda não consolidado |
| `executive-brief-template.md` | Comunicação orientada a decisão |
