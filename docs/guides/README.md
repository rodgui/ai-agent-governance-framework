# Guias de implantação

- [Implementation playbook](framework-implementation-playbook.md) — método canônico com G0–G7, entregáveis e critérios de saída.
- [Roadmap de implantação — 90 dias](implementation-plan-90-days.md) — referência acelerada para quem precisa de uma sequência inicial; não é SLA.
- [Programa de implantação — 24 semanas](implementation-program-24-weeks.md) — pattern detalhado e adaptável, com mapeamento fase↔gate; não é calendário normativo.
- [Plano opcional de piloto e critérios de expansão](pilot-plan.md) — uma rota possível para validar a governança; cohort, phased rollout ou evidência equivalente também são válidos.
- [Capability map — atual versus alvo](capability-map.md) — o que a organização precisa saber fazer, antes de escolher ferramenta.
- [Maturity model](maturity-model.md) — dez dimensões, níveis 0–4, confidence, coverage e target state.

Os guias operacionalizam a [policy modular](../governance/policy.md). Alterações normativas exigem revisão, authority, changelog e release; roadmap, prazo, piloto ou exemplo não criam adoção automática. Organizações podem adaptar a sequência desde que preservem decision rights, gates e evidências.
