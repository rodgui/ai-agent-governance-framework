## Convenções

- use o [ADR template](../../../templates/adr-template.md);
- uma decisão aceita não é reescrita para esconder mudança;
- nova direção supersede a anterior por novo ADR;
- decisão normativa ainda requer authority e processo de policy;
- trade-offs e criteria de reversão são obrigatórios.
