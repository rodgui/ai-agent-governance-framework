- [Operating model](operating-model.md) — roles, authorities, forums, escalation e exception flow.
- [Microsoft Customer Zero — estudo de caso](../explanations/microsoft-agent-governance-case-study.md) — evidência externa declarada, não núcleo normativo.
- [Microsoft × framework crosswalk](../../assessments/comparison-matrices/microsoft-case-study-framework-crosswalk.md) — cobertura e backlog de evolução.
