# Specifications

Use specs para implementação, automação, laboratório complexo, definição de plataforma, framework ou trabalho multi-etapas.

## Estrutura

```text
NNN-capability-name/
├── spec.md
├── plan.md
├── tasks.md
└── validation.md
```

Não use spec para uma nota de estudo comum ou uma pequena correção documental.
